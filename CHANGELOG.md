# Changelog

## 0.3.0

- Toolbar at the top of the editor for paragraphs and headings, bold, italic, strikethrough, lists, quotes, links and images, with inline code, code blocks, math, tables and dividers under ⋯. Turn it off with `mdWysiwyg.toolbar`

## 0.2.0

- Double-click an image to preview it over the editor, with a toggle to actual size
- Ctrl/Cmd+click an image to open the file in VS Code

## 0.1.0

First release.

- WYSIWYG Markdown editor built on Milkdown Crepe, with a slash menu, formatting toolbar and drag handles
- `Ctrl+E` / `Cmd+E` switches between the source and WYSIWYG editors
- Math and Mermaid blocks show as rendered previews until focused
- Notion-style floating table of contents
- Paste or drop images into an `assets/` folder next to the file
- Two-way sync with the source editor, front matter preserved
